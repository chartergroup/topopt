Recorded output of `topopt printcheck` (E1a, fix round 1, Linux x86_64, 2026-10-20). <hook-run> is the run folder of the default hook run
(examples/hook/hook.yaml, 1.2 mm, 1 thread); <ladle-run> is the run folder of examples/ladle/ladle.yaml (voxel 3.25, 80 iterations).
Each .txt file has the command, the text report, the exit code and the line "TIMED" (wall time, peak RSS of the process tree, load average
before and after). The host is shared, so the times depend on the load. hook-default.json is the report of the first command as JSON.
